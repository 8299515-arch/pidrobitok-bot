# Pidrobotok Bot

Telegram-бот для поиска вакансий с AI-агентом, профилем кандидата и автоматическим мониторингом.

## Возможности

- AI-диалог и разбор запроса пользователя.
- Поиск вакансий через подключённые источники.
- Нормализация и дедупликация вакансий.
- Фильтрация по навыкам, городу, зарплате и удалённой работе.
- Ранжирование вакансий относительно профиля кандидата.
- Сохранение профиля и saved searches в SQLite.
- Фоновый мониторинг новых вакансий.
- Telegram-уведомления о новых подходящих вакансиях.

## Требования

- Python 3.11+
- Telegram Bot Token
- Gemini API key

## Локальный запуск

1. Клонируйте репозиторий и перейдите в каталог проекта.
2. Создайте виртуальное окружение:

```bash
python -m venv .venv
```

Windows:

```powershell
.\.venv\Scripts\Activate.ps1
```

Linux/macOS:

```bash
source .venv/bin/activate
```

3. Установите зависимости:

```bash
pip install -r requirements.txt
```

4. Создайте `.env` на основе `.env.example` и заполните только секреты.
5. Запустите:

```bash
python bot.py
```

## Переменные окружения

Обязательные:

```text
TELEGRAM_BOT_TOKEN=...
GEMINI_API_KEY=...
```

Остальные параметры имеют безопасные значения по умолчанию. Локальная SQLite БД не должна коммититься в Git.

## Команды

```text
/start
/help
/profile
/watch <запрос> | <интервал_в_минутах>
/watches
/unwatch <id>
```

Пример:

```text
/watch Python FastAPI Киев от 60000 удалённо | 60
```

После создания мониторинга бот периодически проверяет источники и отправляет только новые подходящие вакансии.

## Безопасность

Никогда не помещайте реальные токены в Git. Если секрет уже был опубликован, его необходимо отозвать и создать новый. `.env` и локальные базы данных должны оставаться вне Git.

## Источники

Источники вакансий подключаются через отдельные адаптеры. Доступность конкретного источника зависит от его публичного интерфейса, API, авторизации и текущих ограничений платформы. Бот не должен обходить CAPTCHA, закрытые каналы или технические ограничения площадок.

## CI

GitHub Actions выполняет компиляцию Python и unit-тесты. Перед слиянием в `main` необходимо дождаться успешного CI и отдельно выполнить runtime-проверку с действующими секретами.
